# contact Management system 
A simple contacts management system built with python
##Features

- Add new contacts
- Search for contacts by name
- Edit existing contact number
- Delete number
- Display all saved contacts
- Save contact data in a Json file

## Technologies used
- python
- json
- os module

## how to run

1. make sure python is installed on your computer
2. download or clone this repository
3. run the python file:
```pash
python temp.py
```
## data stroge
contact information is stored in 'contacts.json' . the prpgram loads saved contacts when is starts and updates the json file when contacts are added, edited or deleted.
